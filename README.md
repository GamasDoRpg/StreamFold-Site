# StreamFold — DEXIS

Página institucional do StreamFold e apresentação comercial do DEXIS para avaliação B2B em piloto privado.

## Estrutura

- `index.html`: página completa, com CSS integrado, layout responsivo e diagrama de reaproveitamento de conteúdo.
- Não exige instalação de dependências, compilação ou JavaScript.
- Não depende de fontes, imagens ou vídeos externos.

## Abrir localmente

Abra `index.html` em um navegador.

## Hospedagem

O conteúdo pode ser servido por uma hospedagem estática. Para GitHub Pages, configure a publicação pela branch `main`, pasta `/` (raiz), nas configurações do repositório. Nenhuma hospedagem ou domínio foi configurado por esta alteração.

## Integrações

- Os botões de contato usam `mailto:pilot@streamfolds.com.br` e abrem o aplicativo de e-mail do visitante. Esta página não inclui formulário nem serviço de envio.
- O link **Pilot portal** aponta para `/pilot`, conforme a página de origem. O portal, sua autenticação e sua hospedagem não estão implementados neste repositório; conecte essa rota ao portal existente ou ajuste o link antes de publicar.
- O diagrama é ilustrativo e não apresenta um benchmark.
- A página mantém o status DEXIS 0.4 e as condições de avaliação do material fornecido. Atualize essas informações quando o produto mudar.

## Verificações realizadas

Estrutura HTML, identificadores únicos, âncoras internas e ausência de dependências externas validados. O portal `/pilot` não foi validado por não fazer parte deste projeto.
